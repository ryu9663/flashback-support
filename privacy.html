플래시백

개인정보 처리방침

플래시백의 기기 내 데이터 처리와 선택적 공유에 관한 안내입니다.

앱에서 처리하는 정보

플래시백은 촬영·선택한 사진과 입력한 문구를 기기 안에서 처리합니다. 앱에서 사진이나 문구를 개발자 서버로 자동 전송하지 않습니다. 계정, 광고, 분석 SDK 및 추적 도구를 사용하지 않습니다.

권한

카메라 권한은 정지 사진 촬영, 사진 추가 권한은 결과 저장에 사용합니다. 기존 사진은 시스템 선택기로 사용자가 선택한 항목만 불러옵니다. 마이크·위치·사진 라이브러리 전체 읽기 권한은 요청하지 않습니다.

기기 내 보관과 삭제

진행 중인 사진 한 세트와 편집 상태를 앱 전용 저장소에 보관합니다. 사진은 긴 변 최대 1,800픽셀로 조정됩니다. 임시 파일은 기기 백업에서 제외하며 새로 찍기를 선택하면 지웁니다. 앱 삭제 시 앱 전용 보관 데이터도 제거됩니다. 촬영·저장 설정은 기기의 앱 설정에 저장됩니다.

사진 앱에 저장한 결과는 사진 앱에서 직접 삭제할 수 있습니다. 불러온 원래 사진은 수정·삭제하지 않습니다.

사용자가 선택하는 공유

시스템 공유 메뉴로 다른 앱에 전달한 이미지는 해당 서비스의 정책을 따릅니다. iCloud 사진 동기화는 사용자의 Apple 설정을 따릅니다.

지원 이메일

이메일 문의는 선택 사항이며 사용자의 메일 앱에서 직접 발송합니다. 앱이 사진이나 진단 자료를 자동 첨부하거나 메일을 자동 발송하지 않습니다. 문의를 보내면 회신 주소와 문의 내용이 이메일 서비스를 통해 운영자에게 전달됩니다. 문의에 불필요한 개인정보를 포함하지 마세요.
